# Organize Braindump

Organize the user's braindump into four sections:

1. **One-sentence summary**
2. **Grouped notes and ideas**
3. **Concrete next actions**, highlighting the single easiest first step
4. **Open questions and parked items**

Keep every detail from the input without inventing anything.
