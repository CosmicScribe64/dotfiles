# LLM Wiki

1. Read Karpathy's guide (https://gist.githubusercontent.com/karpathy/442a6bf555914893e9891c11519de94f/raw/llm-wiki.md) and create the wiki it describes. Use AGENTS.md as the schema.
2. Add a Kanban board page with one column per ticket status. Store each ticket as a wiki page.
3. Add this rule to the schema: move a ticket's card whenever its status changes.
